# 第一人称 (First Person)

为《明日方舟：终末地》提供第一人称视角切换功能，支持真实头部眼位绑定、头颈动作跟随、平滑与迈步转身，以及角色专属趣味视野效果。

> 本仓库基于 [sakevel/Endfield-FirstPerson](https://github.com/sakevel/Endfield-FirstPerson) 0.1.6 继续维护，在其基础上补充了真实眼位跟随、原地转身与视角接管保持等项。

## 操作方式

| 操作 | 默认键位 / 入口 | 说明 |
|---|---|---|
| **切换视角** | `Ctrl+F5` | 切换第一人称与第三人称（可在游戏「设置 → 按键绑定」修改） |
| **参数调节** | `ESC` → 模组菜单 → 第一人称 | 实时调整视野（FOV）、灵敏度、眼高及跟随选项 |

> 过场动画、剧情对话或打开全屏菜单时，相机会自动交还游戏原生控制。

## 功能特性

- **自由视角控制**：支持 40°~120° 垂直视野（FOV）自由调节与独立视角灵敏度倍率。
- **角色身体可见**：低头时可见自身躯干与四肢，第一人称下自动隐藏头部模型，避免穿模遮挡视线。
- **真实眼位跟随**：镜头直接取头骨的世界坐标与姿态，跑动、蹲伏、空翻时视线随身体一起走；位置通路不做任何滤波，避免滞后。
- **头颈转动与镜头绑定**：镜头绑定至真实头部位置，转动视角时跟随头颈关节弧线运动，跟随强度可调，可另开头部侧倾。
- **平滑策略**：平滑只作用于头骨动画偏移这一段，鼠标输入不经过滤波，所以顺滑与跟手不冲突；单帧大角度变化不做硬吸附，避免空翻时的顿挫。
- **姿态跟随与转身**：视角偏离角色朝向超过阈值时自动平滑转身，可选触发游戏原生迈步转身动作。
- **视角接管保持**：输入封锁、鼠标光标、界面层、临时相机、角色演出、相机控制器六种情况下，可分别选择不把相机交还游戏。
- **角色专属视野**：
  - **汤汤**：左侧视野圆弧眼罩遮挡效果
  - **管理员**：抑制器周期性地形扫描波纹与光带效果
  - **大潘**：墨镜滤镜暗化效果

## 配置项

共 33 项，全部在 `ESC` → 模组菜单 → 第一人称 面板内实时生效。其中「视角接管诊断」仅用于排查相机控制权问题，日常使用保持关闭。
